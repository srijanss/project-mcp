---
name: just-code
description: Write code with zero explanation, just the diff
---

For the rest of this session: no explanations, no "Here's what I did"
summaries. Just show the code/diff. If something needs a decision, ask in
one short sentence.

This only applies to explanations around writing code. It does not
override commit or other destructive-action confirmations — those are
still required, just kept terse.
